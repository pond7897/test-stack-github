# Intro

เอกสารชุดนี้ใช้ทดสอบ GitHub Stacked Pull Requests โดยแยกเป็น 3 ชั้น
แต่ละชั้นเพิ่มไฟล์ใหม่ 1 ไฟล์ และลิงก์ต่อจากชั้นก่อนหน้า

## โครงสร้างเอกสาร

| ชั้น | ไฟล์ | เนื้อหา |
|---|---|---|
| 1 | `docs/intro.md` | ภาพรวม (ไฟล์นี้) |
| 2 | `docs/usage.md` | วิธีใช้ |
| 3 | `docs/faq.md` | คำถามที่พบบ่อย |
