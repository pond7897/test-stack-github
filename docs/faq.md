# FAQ

ต่อจาก [Usage](./usage.md)

**ถาม: merge ชั้นล่างก่อนได้ไหม**
ได้ PR ชั้นบนจะ rebase และ retarget base ให้อัตโนมัติ

**ถาม: merge ชั้นบนสุดเลยได้ไหม**
ได้ จะได้ชั้นล่างที่ยังไม่ merge ติดไปทั้งหมดในครั้งเดียว

**ถาม: แก้ไฟล์ที่ชั้นล่างแล้วชั้นบนต้องทำอะไร**
รัน `gh stack sync` จะ rebase ไล่ขึ้นทั้งกองให้เอง

**ถาม: branch protection ยังทำงานไหม**
ทำงานปกติ required checks เดิมยังบังคับใช้
